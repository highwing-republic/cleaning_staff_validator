# 清掃勤務表作成アプリ

旅館・ホテルの清掃スタッフについて、通常勤務条件・勤務希望・予約状況・必要人数から
10〜14日程度の勤務表を作成する Streamlit アプリです。

勤務表は OR-Tools CP-SAT で自動作成し、画面上で手直し・固定・再生成・日ごとの確定を行い、
最後に A4 横の Excel として印刷できます。

> リポジトリ名は `cleaning_staff_validator` のままですが、
> アプリの役割は勤怠CSVの検証から勤務表の作成へ移っています。

## 運用の流れ（若女将向け）

```
スタッフ本人 → 紙で「普段と違う希望」だけ提出
若女将      → アプリへ転記 → 予約室数・必要人数を入力
            → 勤務案を作成 → 必要な箇所を手直し → 日ごとに確定
            → Excel を印刷して配布
当日        → 紙へ手書きで変更
```

画面は使う順番に並んでいます。

1. **スタッフ管理** — スタッフと通常の勤務条件（曜日・勤務時間・ロール・総合スキル・特殊スキル）を確認する
2. **勤務希望** — 紙に書かれた「普段と違う希望」を転記する（絶対休み／できれば休み／早上がり／遅出／通常休みだが勤務可能）
3. **予約・必要人数** — 対象期間の予約室数と必要人数・最大人数・ロール条件・スキル条件を入力する
4. **シフト生成** — 勤務案を自動作成し、下書きとして保存する
5. **勤務表調整** — 出勤／休みを手直しし、動かしたくない日を固定して再生成し、日ごとに確定する
6. **勤務表出力** — 人数・ロール・スキルの不足を最終確認し、印刷用 Excel を出力する

左メニューの「補助機能（勤怠CSV）」には、以前からの **勤怠CSV取込** と **勤怠データ検証** が残っています。
こちらは勤怠システムから出した実績CSVを確認するための機能で、勤務表づくりには使いません。

## 実装済みの機能

- スタッフ管理（ロール・総合スキル・通常勤務曜日・通常勤務時間・特殊スキル・目標勤務日数／週・最大連続勤務日数）
- 期間別の勤務希望（絶対休み／できれば休み／早上がり／遅出／通常休みだが勤務可能／備考）
- 予約室数・必要人数・最大人数・ロール別必要人数・スキル条件の日別入力（CSV/Excel 取り込みにも対応）
- CP-SAT による勤務案の自動作成（最低必要人数・ロール・スキル・最大連勤・勤務可能条件を考慮）
- 目標勤務日数と公平性を優先し、必要に応じて最低必要人数を上回る配置を許容
- 目標未設定のチェッカーは週5日、その他は最低必要人数の平均を自動目安として配置
- できれば休みの尊重と目標勤務日数／週への配分（多段最適化）
- 勤務案の下書き保存、手修正、固定、固定を守った再生成（反映前に変更内容を確認）
- 日ごとの確定・確定解除
- 保存済み勤務表の検証（人数不足・最大人数超過・ロール不足・スキル不足・要件未設定・未作成・下書き）
- 印刷用 Excel 出力（勤務表／日別確認／問題一覧／出力情報、A4横・横1ページ、当日手書き用の備考欄つき）
- 補助機能: 勤怠CSV取込と勤怠データ検証（旧機能）

## 技術構成

- Python 3.10 以上（Windows では 3.12 で動作確認）
- Streamlit（画面）
- SQLite（`data/app.db`）
- OR-Tools CP-SAT（勤務案の作成）
- openpyxl（Excel 出力）
- pandas（表の表示・CSV取り込み）
- pytest（テスト）

### ディレクトリ

```
app.py            エントリポイント（左メニュー・ホーム画面）
pages/            画面（ファイル名の番号は作成順。表示順は app.py で決める）
src/              業務ロジック
  navigation.py   アプリ名・画面名・メニューの並び
  database.py     スキーマと移行
  repositories.py SQL
  services.py     画面から呼ぶ業務処理
  shift_generation.py        CP-SAT 本体（DB・Streamlit に依存しない）
  schedule_validation_adapter.py  保存済み勤務表の検証
  schedule_excel.py          印刷用 Excel
tests/            pytest
sample/           サンプル CSV
```

## 起動方法

Windows（PowerShell）:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

データベースは既定で `data/app.db` に作られます。別の場所を使う場合は
環境変数 `CLEANING_STAFF_VALIDATOR_DB_PATH` にファイルパスを設定してください。

## テスト

```bash
pytest -q
```

## 運用上の注意

- 当日変更は印刷した勤務表へ手書きで対応し、アプリ上の勤務表は前日までの計画表として扱います。
  当日の実績をアプリへ戻す機能はありません。
- 本番利用前・大きな変更前には `data/app.db` をバックアップしてください（自動バックアップはありません）。
- 予約室数から必要人数は自動計算しません。必要人数は若女将が判断して入力します。
- 1人で使う前提です（複数人の同時編集・ログイン認証はありません）。
